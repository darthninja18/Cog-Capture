Changelog

This history starts with the earliest Cog & Capture release notes we can currently verify. Older releases can be added as we recover them.

1.4.6 — Hotfix 6

Pixelmon Pasture update

  • Updated Pixelmon Pasture to 0.3.1.
  • Confirmed the updated Pasture is included in the server pack.

1.4.3 — Hotfix 3

Pasture hotfix

  • Added the new Pixelmon Pasture build to the server pack.
  • Budding Crystals remained installed; its planned removal was moved to a later update.
